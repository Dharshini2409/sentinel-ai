SYSTEM ONLINE
System Architecture
A single alert flows straight down through five simple Python agents. Each agent does one job and hands the enriched alert to the next.
SIEM / EDR
Raw alerts from security tools (mocked for demo)
Alert Intake Agent
Normalizes format, assigns unique alert ID
Context Enrichment Agent
Attaches asset criticality and user privilege
Threat Intelligence Agent
Checks IP / domain / hash against known IOCs
False Positive Agent
Flags alerts matching known benign patterns
Priority Ranking Agent
Computes explainable weighted risk score
Analyst Dashboard
Ranked queue with full reasoning per alert
Human Decision
Analyst reviews and approves next action
No automatic remediation. Sentinel AI only recommends — a human analyst always approves.
Tech stack: Python + Flask backend, HTML/CSS/vanilla JS frontend, JSON-based mock data, Chart.js for analytics. No React, no Docker, no external AI dependency required.
